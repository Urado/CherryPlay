# Переменные окружения CherryPlayWeb

Переменные окружения для веб-приложения (в том числе **VITE_API_URL**, **VITE_SIGNALR_URL**) описаны в **едином справочнике репозитория**:

**[ENV.md](../ENV.md)** (в корне репозитория).

Там приведены все переменные для бэкенда, фронта, БД и деплоя; разделы «Разработка и продакшен» и маппинг для бэкенда. Фронт читает `.env` из **корня репозитория** (см. `vite.config.ts`, `envDir`).
