# Cursor Workspace Conventions

Use this folder for reusable agent behavior, rules, and workflows.

## Start here

- Style guide for authoring and updates: `STYLE_GUIDE_AGENTS_RULES_SKILLS.md`

## Structure

- `agents/` — role definitions for subagents.
- `rules/` — policy and behavior constraints.
- `skills/` — reusable multi-step workflows.

## Maintenance

- Keep terminology consistent across files (`Critical`, `Warnings`, `Suggestions`).
- Prefer small, scoped updates and avoid contradictory instructions between files.
- When adding new files, follow the style guide templates.
