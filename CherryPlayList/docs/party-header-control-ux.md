# Пульт вечеринки в шапке — зафиксированные UX-решения

Документ фиксирует продуктовые договорённости по редизайну управления вечеринкой в CherryPlayList (обсуждение с экспертной панелью и уточнения Павла, август 2026).

**Статус:** partially as-built (desktop CherryPlayList, август 2026). Крупный статус **Пауза** на пульте — as-built (overlay по `playbackStatus === 'paused'`). Крупный статус **Конец**, `programEnded` и напоминание-таймер (§7.6) — **spec / residual**, ещё не в коде пульта.  
**Область:** только desktop CherryPlayList. Web-кабинет — позже отдельным редизайном (вне scope).  
**Связанные документы:** [modules/workspaces/party.md](./modules/workspaces/party.md), [online-mode-ux-synthesis.md](./online-mode-ux-synthesis.md), [GLOSSARY.md](../../GLOSSARY.md).

Термин **pill / таблетка** в этом документе **не используем**. В шапке — **пульт вечеринки** (`HeaderPartyStatus` / `header-party-control`). Не путать с **playback pill** (`HeaderPlaybackPill`) — это отдельный chrome сессии CherryPlay.

**«Мета»** в старых заметках = **название и описание вечеринки** (и связанные поля формы настроек). Дальше пишем по-русски: название / описание / настройки вечеринки.

UI-метки этапов и крупного статуса — **только** по [GLOSSARY — lifecycle](../../GLOSSARY.md#cherryplaylist-lifecycle-ui-labels): **Не создана** / **Ждёт начала** / **Идёт** / **В архиве**. Короткие синонимы (локально / готово / играем / архив) в UI **не используем**. Дополнительно на пульте (крупный статус, не отдельные точки полоски): **Пауза** (as-built); **Конец** (spec — см. §7.6 residual). Legacy **Черновик** на пульте возможен как крупный статус (не точка полоски); happy-path create → сразу **Ждёт начала**.

---

## 1. Цель

Пользователь всегда видит:

1. **где вечеринка по этапам**;
2. **что сделать дальше**;
3. **куда это ведёт** — без старта проигрывания из шапки.

Старт музыки / трансляции остаётся у кнопки **«Начать проигрывание»** (CherryPlay) или **«Включить онлайн»** (AIMP). Пульт **ведёт** к этой кнопке, но **не запускает** сессию сам.

---

## 2. Четыре этапа (полоска всегда видна)

Иконки этапов **всегда** на пульте. **Не кликабельны** — только подсказки (tooltip). Подписи точек и крупный статус — метки GLOSSARY.

```
  [ 1 ]──[ 2 ]──[ 3 ]──[ 4 ]
Не создана  Ждёт    Идёт   В архиве
            начала
```

| Точка | Метка (GLOSSARY) | Смысл                                                                         |
| ----- | ---------------- | ----------------------------------------------------------------------------- |
| **1** | **Не создана**   | Вечеринки на сервере ещё нет (`linkedParty` отсутствует)                      |
| **2** | **Ждёт начала**  | На сайте (`ready`), ждёт запуска проигрывания / после Stop без «Конца»        |
| **3** | **Идёт**         | Активная session / трансляция; также активная точка при **Пауза** и **Конец** |
| **4** | **В архиве**     | `completed`                                                                   |

Крупный статус на пульте может отличаться от подписи активной точки:

| Крупный статус  | Активная точка полоски | Когда                                       |
| --------------- | ---------------------- | ------------------------------------------- |
| **Не создана**  | 1                      | нет `linkedParty`                           |
| **Ждёт начала** | 2                      | `ready`, нет session (обычный idle)         |
| **Идёт**        | 3                      | `ready` + session, играет                   |
| **Пауза**       | **3**                  | session на паузе (ещё не Stop); as-built на пульте      |
| **Конец**       | **3**                  | доиграл последний трек (spec / residual — §7.6)         |
| **В архиве**    | 4                      | `completed`                                 |

Legacy **Черновик** в полоске **не показываем** (вне happy-path create; отдельная доработка не в scope этой фиксации).

Сопоставление с сервером: отсутствие link → Не создана; `ready` без session → Ждёт начала; `ready` + session → Идёт (или Пауза / Конец по UI); `completed` → В архиве.

## 3. Роли поверхностей

| Где                                             | Назначение                                                                                         |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Пульт в шапке**                               | 4 этапа, крупный статус, CTA следующего шага, иконка **«Обновить на сайте»**, вход в настройки (⚙) |
| **Панелька рядом с кнопкой**                    | Только сценарий «к игре» (как панель настройки трека — не на весь экран)                           |
| **Окно «Вечеринка» (workspace) + боковое меню** | Вариант **B**: свойства вечеринки + дизайн в одном окне; см. §8                                    |
| **Вкладка / раздел «О вечеринке»**              | Метаданные, каталог, привязка, URL, сохранить; опасная зона **«В архив»**                          |
| **Холст «Дизайн»**                              | Тема, крутилки, отображение треков                                                                 |
| **Плеер / AIMP**                                | Старт и остановка проигрывания / трансляции                                                        |

Пульт **не показываем**, если выключена галочка **«Онлайн»** (блок убирается целиком).

## 4. Пульт в шапке (форма)

```
┌──────────────────────────────────────────────────────┐
│  ○──●──○──○     этапы (только подсказки)             │
│                                                      │
│  Крупно: текущий статус                              │
│  [ CTA следующего шага ]  [↑ обновить]  [⚙]          │
└──────────────────────────────────────────────────────┘
```

Правила (as-built):

- Из пульта **нельзя** начать проигрывание / трансляцию.
- CTA-метки: **Создать** / **К настройкам** (legacy черновик) / **К игре** / **К остановке** / **Вернуть из архива**.
- В статусе **Идёт** CTA **«К остановке»** → подсветка **«Остановить проигрывание»** (AIMP: **«Выключить онлайн»**) — **не** паузу плеера.
- В статусе **Пауза** CTA **«К игре»** → подсветка продолжения на месте (Play / resume), не архив.
- **«В архив»** на пульте **нет** — только в опасной зоне «О вечеринке».
- **«Вернуть из архива»** — CTA пульта с confirm; в опасной зоне редактора **нет**.
- Иконка **«Обновить на сайте»** (Publish): tooltip; disabled + причина при offline / нет link / не авторизован / нечего отправлять; индикатор dirty («есть изменения для сайта»).
- ⚙ → `requestOpenPartyEditorAbout()` (раздел **«О вечеринке»**).

## 5. Настройки вечеринки (раздел «О вечеринке»)

В боковом меню окна вечеринки — раздел свойств. Доступен **до создания** и **после**. Сюда переезжает почти всё бывших настроек **кроме дизайна**, плюс действия, ранее жившие в toolbar Editor.

### Поля и действия в «О вечеринке»

- Название (`partyName`), при наличии в UI — title / subtitle
- Описание, краткое описание (`shortDescription`)
- Место, город, расписание (`place`, `city`, `schedule`)
- Начало / конец события, таймзона (`eventDateTime`, `eventEndDateTime`, `timeZone`)
- Внешняя ссылка (`externalLinkUrl`, `externalLinkText`)
- Теги танцев (`danceTags`)
- Каталог: на create — чекбокс; после — toggle **«По ссылке»** / **«В каталоге»**
- **Привязать существующую…** (пока нет `linkedParty`)
- **Скопировать URL** (когда есть URL)
- **Сохранить** — метаданные вечеринки на сервере (**без** обновления плейлиста; Publish ≠ Save)
- Опасная зона (боковое меню, не About-toolbar): **«В архив»** (с подтверждением)
- Legacy `draft`: **«Сделать доступной»** в About (не на пульте)

**Не здесь (холст «Дизайн»):** `themeId`, customization / крутилки, отображение треков.

**Publish** на этой вкладке **нет** — только иконкой на пульте (§4). **«Вернуть из архива»** — только с пульта (§7.6), не в опасной зоне.

### «В архив» — доступность

| Контекст                              | «В архив» в опасной зоне                                                                                  |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Идёт** (live: CherryPlay session играет / AIMP live-stream) | Видна, **неактивна** (`archiveBlockedByLive`); клик → пояснение, почему нельзя сейчас |
| **Пауза**                             | Видна, **приглушена** (`archiveQuiet`); не основной сценарий завершения                                   |
| После **Stop** / idle **Ждёт начала** | Снова можно (кнопка активна, с «точно?»)                                                                  |
| **Конец** (таймер)                    | Архивация по-прежнему через настройки; таймер сам **не** архивирует                                       |
| **В архиве**                          | Опасной зоны архива **нет**; возврат — CTA **пульта** (§7.6)                                              |

## 6. Окно вечеринки — дизайн + меню (вариант B)

v1 = **одно окно** с **сворачиваемым боковым меню** (вариант B). Split (A) **не** делаем.

```
ШАПКА:  ○─●─○─○  Ждёт начала  [ К игре ]  [↑]  [⚙]

ОКНО ВЕЧЕРИНКИ:
┌─────┬─────────────────────┐
│ ≡   │  дизайн-холст       │
│О веч│                     │
│Дизайн│                    │
│Опасн.│  (архив глубоко)   │
└─────┴─────────────────────┘
```

В меню: «О вечеринке», «Дизайн», опасная зона (архив только при `ready`).  
**Не** класть сюда Ready / старт игры / остановку проигрывания / unarchive.  
По умолчанию меню **свёрнуто**, когда пользователь на холсте **Дизайн** (`selectPartyEditorDesign` → `editorNavExpanded: false`).

## 7. Сценарии и матрица CTA

### 7.0. Матрица состояний

| Состояние                   | Точка | Крупный статус | CTA пульта                                             | Куда                            |
| --------------------------- | ----- | -------------- | ------------------------------------------------------ | ------------------------------- |
| нет `linkedParty`           | 1     | Не создана     | **Создать**                                            | раздел «О вечеринке» → create   |
| legacy `draft`              | 2*    | Черновик       | **К настройкам**                                       | раздел «О вечеринке»            |
| `ready`, нет session (idle) | 2     | Ждёт начала    | **К игре**                                             | панелька + подсветка Start      |
| `ready` + live, играет      | 3     | Идёт           | **К остановке**                                        | подсветка Stop / «Выключить онлайн» |
| session / live на паузе     | **3** | **Пауза**      | **К игре** (подсветка Play / resume)                   | **не** архив с пульта           |
| последний трек доиграл      | **3** | **Конец**      | **К игре** + напоминание-таймер (residual)             | таймер не архивирует; **не as-built** |
| `completed`                 | 4     | В архиве       | **Вернуть из архива**                                  | confirm → снова **Ждёт начала** |

\* Точка полоски для **Черновик** = 2 (**Ждёт начала**); отдельной точки «Черновик» нет. Draft / legacy в happy-path create **не** описываем подробно.

### 7.1. Не создана → Ждёт начала

CTA ведёт в раздел **«О вечеринке»**. После успешного create этап = **Ждёт начала**.

```
Не создана  →  [ Создать ]
                    ↓
         раздел «О вечеринке»
                    ↓
              Ждёт начала
```

### 7.2. Ждёт начала → к игре (панелька, не полноэкран)

**Каждое** нажатие CTA **«К игре»**:

- не полноэкранный модал;
- **панелька рядом** (как у настройки трека);
- **подсветка** целевой кнопки **без** доп. кнопок на самой подсветке;
- доп. кнопка **только** **«Перейти»** — и только если ещё не на нужном экране проигрывания.

Целевая кнопка подсветки (scoped по `streamingSource`):

- CherryPlay player → **«Начать проигрывание»** / при паузе — resume на месте;
- AIMP → **«Включить онлайн»** (старт live-stream; не путать с глобальной настройкой **«Онлайн»** в Settings). Те же правила блокировок, что для CherryPlay.

**Раскладки «Играть для гостей» ещё нет / нет окна проигрывания:**

```
Пульт: Ждёт начала  [ К игре ]
                    │
                    ▼
         ┌─────────────────────┐
         │ Вечеринка готова.   │
         │ Запуск — кнопкой    │
         │ «Начать…» на экране │
         │                     │
         │      [ Перейти ]    │
         └─────────────────────┘
                    │
                    ▼
         раскладка «Играть для гостей»
         + подсветка «Начать проигрывание»
           (AIMP → «Включить онлайн»)
```

**Окно проигрывания / нужная раскладка уже есть:**

```
Пульт: Ждёт начала  [ К игре ]
                    │
                    ▼
         ┌─────────────────────┐
         │ Вечеринка готова.   │
         │ Нажмите «Начать…»   │
         │ (кнопок нет)        │
         └─────────────────────┘
         + только подсветка целевой кнопки
```

Музыка / трансляция **сами не стартуют**.

### 7.3. Подсветка (правила)

- Мигание / акцент **5 секунд**, подсветка **краёв** целевой кнопки.
- Цель выбирается по `streamingSource` (CherryPlay vs AIMP).
- Кнопка в зоне видимости; при необходимости — проскроллить, затем 5 с.
- Повторный клик CTA — снова запустить 5 с.
- Нет целевой кнопки в layout — панелька + **«Перейти»** (или пояснение), без фантомной подсветки.
- Dismiss: истечение 5 с, Escape, клик вне / по другой зоне.
- Не вечное агрессивное мигание.

### 7.4. Идёт

- Из пульта **нельзя** завершить / отправить в архив.
- CTA **«К остановке»** → подсветка **«Остановить проигрывание»** (AIMP: **«Выключить онлайн»**). Подсветка без доп. кнопок (§7.3).

```
Пульт: Идёт  [ К остановке ]
                │
                ▼ подсветка
     [ Остановить проигрывание ]
       (AIMP → «Выключить онлайн»)
```

### 7.5. Пауза

Крупный статус **Пауза**, точка полоски **3 (Идёт)**.

- Архивацию **не** предлагаем с пульта.
- В опасной зоне кнопка архива **приглушена** (`archiveQuiet`), не основной сценарий.
- CTA **«К игре»** → подсветка продолжения на месте.
- После полного **Stop** / конца live → статус **Ждёт начала** (точка 2); **«В архив»** снова активна в опасной зоне (с подтверждением).

### 7.6. Конец программы = доиграл последний трек

**Статус реализации:** spec / residual — **не as-built** на пульте. В коде пока нет `programEnded` / `clearPartyProgramEnded`, детекции «последний трек доиграл» для CherryPlay+AIMP и напоминания-таймера; крупный статус **Конец** на пульте не выставляется.

Продуктовый замысел (когда будет wired):

Крупный статус **Конец**, точка полоски **3 (Идёт)**. Детекция для CherryPlay и AIMP (`programEnded`).

Стартует **напоминание-таймер** (сам **не** архивирует). Базовый интервал **20 мин**, snooze **экспоненциально**: 20 → 40 → 80 → … мин.

- Если снова Play / добавили треки — **таймер отменить** (`clearPartyProgramEnded`).
- Таймер можно **просто закрыть** и забыть.
- По клику на таймер: **ещё подождать** или **отменить**.

```
Последний трек доиграл
         │
         ▼
   ┌─────────────────────────┐
   │ Напоминание  20:00      │
   │ (закрыть = ок)          │
   │ клик → [ Ещё подождать ]│
   │         [ Отменить ]    │
   └─────────────────────────┘
```

«В архив» — в настройках (опасная зона), не на пульте.

### 7.7. В архиве

Точка 4, крупный статус **В архиве**.

CTA пульта = **«Вернуть из архива»** → `window.confirm` → после успеха статус **Ждёт начала**. В Editor danger zone unarchive **нет**.

Переход **в** архив — осознанный (подтверждение), кнопка глубоко в опасной зоне; при live — disabled + пояснение (§5).

## 8. Выбор поверхности: зафиксирован B

Исторический вердикт панели (до фиксации автора): A дешевле на первую поставку; B допустим продуктово.

**Решение автора (2026-08-07): v1 = вариант B.** Риски сочтены незначительными. Вариант A не реализуем.

Требования к B:

- статус и следующий шаг — только в **шапке**;
- архив — глубоко, с «точно?»; при live — disabled + пояснение;
- боковое меню по умолчанию **свёрнуто** на холсте дизайна;
- в меню **нет** старта/стопа проигрывания.

## 9. Сводная схема

```
Не создана ──«О вечеринке» / create──► Ждёт начала
                                         │
                              панелька у кнопки
                              (+ Перейти, если надо)
                                         │
                                         ▼
                                       Идёт
                        (подсветка «Остановить…»)
                           │            │
                        Пауза         Конец
                     (точка 3)     (точка 3 + таймер)
                           │            │
                      Stop / …     настройки → архив
                           ▼
                     Ждёт начала ──настройки──► В архиве
                                         ▲
                         Вернуть (пульт + confirm)
```

```
Пульт в шапке     = этапы + статус + CTA + Publish-иконка + ⚙
Панелька рядом    = только «к игре»
Окно вечеринки    = B: меню «О вечеринке» / Дизайн / опасное
Плеер / AIMP      = старт и остановка («Начать/Остановить проигрывание»; AIMP «Включить/Выключить онлайн»)
Онлайн выкл       = пульт скрыт целиком
```

## 10. Offline / auth / онлайн

- **«Онлайн» выключен** — блок пульта **убираем** (не показываем).
- **Server unreachable** — пульт может оставаться видимым при включённом онлайне; сетевые действия (create, Publish, lifecycle) disabled + понятная причина (баннер / tooltip), по духу текущего Party Editor; secondary на пульте: **нет связи**.
- **Не авторизован** — CTA **Создать** блокируется с пояснением («Для создания необходимо войти в аккаунт»).

---

## 11. Вне scope этой фиксации

- Редизайн Web-кабинета организатора.
- Авто-архивация по таймеру (сейчас только напоминание — и само напоминание ещё residual, см. §7.6).
- Крупный статус **Конец** / `programEnded` / reminder на пульте (spec; не as-built).
- Показ Черновика **отдельной точкой** в полоске этапов и полная матрица для legacy `draft` (крупный статус + CTA «К настройкам» есть; отдельной точки нет).
- Старт сессии из пульта шапки.
- Вариант A (split попап / только-дизайн окно).
- Кнопка **«Играть для гостей»** в пульте (убрана; раскладка — через **Рабочие окна** / guide **«Перейти»**).
