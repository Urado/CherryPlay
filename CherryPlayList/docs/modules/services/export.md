# Export

Модуль экспорта плейлистов в различные форматы.

## Описание

Сервис для экспорта плейлистов с поддержкой нескольких стратегий экспорта. Все операции выполняются через IPC в Electron main process.

## Основные компоненты

- **exportService** (`src/shared/services/exportService.ts`) - Сервис экспорта
- **ExportModal** (`src/app/components/ExportModal.tsx`) - Модальное окно настроек экспорта
- Пункт **Экспорт** в меню **Файл** (`AppHeader`) — tooltip: «Экспортирует файлы плейлиста в выбранную папку»
- IPC handlers (`electron/ipc/export.ts`) - Обработчики в main process

## Стратегии экспорта

### 1. Copy with Number Prefix

Копирование треков в папку с автоматической нумерацией (например: `01 - Track Name.mp3`). Порядок треков берётся из плейлиста на момент нажатия «Экспортировать» через `getAllTracksInOrder()` (тот же порядок, что и в отображении).

### 2. AIMP Playlist (M3U8)

Экспорт в формате AIMP с относительными путями. Создаёт подпапку с треками и `.m3u8` файлом.

## Функциональность

- Выбор папки для экспорта
- Выбор стратегии экспорта
- Обработка ошибок с детализацией успешных/неудачных операций
- Toast только при ошибках / предупреждениях (пустой плейлист, нет папки, сбой экспорта); успешный экспорт закрывает модалку **без** toast
