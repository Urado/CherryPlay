# Storage

Система надёжного хранения данных через localforage (IndexedDB).

## Описание

Адаптер для Zustand persist middleware, использующий localforage вместо localStorage для надёжного сохранения данных между сессиями, включая спящий режим системы.

## Основные компоненты

- **electronStorage** (`src/shared/storage/electronStorage.ts`) - Адаптер для Zustand

## Проблема, которую решает

- `localStorage` может терять данные при спящем режиме или аварийном завершении
- `localStorage` синхронный и блокирует UI поток
- Ограниченный объём хранения (~5-10 МБ)

## Преимущества localforage

- **Асинхронное хранение** - не блокирует UI поток
- **Надёжность** - данные сохраняются на диск, не теряются при спящем режиме
- **Больший объём** - до 50% свободного места на диске
- **Поддержка сложных типов** - объекты, массивы, Blobs без сериализации
- **Автоматический выбор драйвера** - IndexedDB > WebSQL > localStorage

## Использование

Все Zustand stores с `persist` middleware используют `electronStorage` для сохранения состояния между сессиями.
