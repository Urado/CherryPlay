# Collections

Подборка — список треков внутри текущего проекта. Workspace-зона показывает выбранную подборку; данные принадлежат проекту и остаются в нём после закрытия окна.

## Управление подборками

В шапке зоны находится переключатель с именем подборки и выпадающим списком всех подборок проекта. Выбор переключает текущее окно; несколько окон могут показывать одну подборку и сразу видеть её изменения. Последний пункт меню создаёт подборку и переключает на неё текущее окно. Переименование доступно отдельной кнопкой-карандаш рядом с названием; действие переименования из меню удалено.

При появлении новой зоны `collection` приложение назначает первую подборку, которая не отображается в других зонах текущего layout. Если свободной нет, создаётся подборка `Подборка N`. При восстановлении существующей привязки сохраняется именно она. Закрытие зоны снимает привязку окна, не удаляя подборку и её содержимое. При смене layout свободность вычисляется только по окнам активного layout.

### Удаление подборки

В выпадающем списке подборок у каждой записи есть кнопка **×**. Нажатие открывает деструктивный диалог подтверждения, который предупреждает о необратимом удалении. После подтверждения удаляются сама подборка вместе с её треками и все привязки `workspaceId → collectionId`, указывающие на неё.

Каждая активная зона `collection`, привязанная к удалённой подборке в текущем layout, повторно инициализируется обычным алгоритмом автопривязки: получает первую свободную подборку с учётом остальных зон активного layout, а если свободной нет — создаётся новая. Если у удаляемой подборки нет активных привязок, другие зоны не переназначаются.

## Данные и история

Сущности подборок (`id`, `name`, `items`) входят в `projectStore` и общий persist проекта. Привязки `workspaceId → collectionId` сохраняются отдельно от содержимого. Изменение подборки помечает проект изменённым; при переключении окон общий список команд сохраняет привязку к исходной сущности, поэтому Undo работает после переключения или закрытия окна. Выделение элементов остаётся локальным для каждого окна.

Команды и UI пока используют совместимый workspace-store адаптер из `projectStoreFactory`. Он направляет операции на сущность подборки, но не создаёт для неё отдельный persist. Удаление этого адаптера запланировано отдельной задачей технического долга.

Старые записи `cherryplaylist-<workspaceId>` читаются при миграции локального проекта для collection-зон, найденных в текущем layout, пользовательских layout и встроенных override. Записи переносятся в проект и связываются с исходными workspace ID. Миграция не удаляет исходные ключи. Записи, чей workspace ID больше не присутствует в этих layout, автоматически найти нельзя; такие сиротские записи остаются в хранилище.

## Функции списка

- Неограниченное число треков (`maxTracks: null`), выделение, перетаскивание, Undo/Redo и статистика.
- Перетаскивание между подборками и основным плейлистом.
- JSON-экспорт и копирование аудиофайлов в папку для подборки не предусмотрены.
- Пустая подборка сохраняется; закрытие окна не очищает и не удаляет данные.
