# Collections

Облегчённые плейлисты для временного хранения треков без ограничений.

## Описание

Коллекции - это упрощённые плейлисты без ограничений на количество треков. Используются для временного хранения и организации треков перед добавлением в основной плейлист.

## Основные компоненты

- **CollectionView** (`src/workspaces/collection/CollectionView.tsx`) - Компонент коллекции
- **trackWorkspaceStoreFactory** - Factory для создания stores коллекций

## Функциональность

- Неограниченное количество треков (`maxTracks: null`)
- Полная функциональность: выделение, перетаскивание, undo/redo, статистика
- Cross-workspace drag-and-drop (между коллекциями и плейлистами)
- Переименование и отображение статистики (количество треков, общая длительность)
- Автоматическое сохранение между запусками (localforage)
- Экспорт в JSON формат

## Отличия от плейлиста

- Нет ограничений на количество треков
- Отдельный store для каждой коллекции
- Используются в layout presets: **«Сборка плейлиста»** и **«Коллекции вертикально»**
