# Collections

Облегчённые плейлисты для временного хранения треков без ограничений.

**Отображаемое имя зоны в UI:** **«Подборка»** (`collection` → `workspaceDisplayNames.ts`). Внутренний id — `collection`.

## Описание

Подборки — упрощённые плейлисты без ограничений на количество треков. Используются для временного хранения и организации треков перед добавлением в основной плейлист.

## Основные компоненты

- **CollectionView** (`src/workspaces/collection/CollectionView.tsx`) - Компонент подборки
- **trackWorkspaceStoreFactory** - Factory для создания stores подборок

## Функциональность

- Неограниченное количество треков (`maxTracks: null`)
- Полная функциональность: выделение, перетаскивание, undo/redo, статистика
- Cross-workspace drag-and-drop (между подборками и плейлистами)
- Переименование и отображение статистики (количество треков, общая длительность)
- Автоматическое сохранение между запусками (localforage)
- Экспорт в JSON формат

## Отличия от плейлиста

- Нет ограничений на количество треков
- Отдельный store для каждой подборки
- Используются в layout presets **«Сборка плейлиста»** (`collections`, `collections-vertical`; у вертикального — secondary про вертикальную раскладку)
