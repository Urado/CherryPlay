# Playlist

Модуль основного плейлиста для создания последовательностей треков.

## Описание

Главный workspace для создания и редактирования плейлистов. Поддерживает drag-and-drop, выделение, группы треков и экспорт.

## Основные компоненты

- **PlaylistView** (`src/workspaces/playlist/PlaylistView.tsx`) - Основной компонент
- **projectStore** - Используется для хранения данных плейлиста

## Функциональность

- Добавление треков через drag-and-drop из FileBrowser
- Переупорядочивание треков внутри плейлиста
- Выделение треков (single, multiple, range)
- Группы треков (создание, расформирование, переименование)
- Отображение общей длительности плейлиста
- Отображение длительности каждого трека (у дубликатов — одного и того же файла по пути — длительность показывается у каждой строки)
- Предупреждение о дубликатах: красная точка рядом с длительностью и подсказка при наведении «Дубликат: тот же файл уже есть в плейлисте»
- Undo/Redo (Ctrl+Z / Ctrl+Y)
- Сохранение/загрузка проектов (.cherry формат)
- Экспорт плейлиста

## Интеграция

- Использует `projectStore` для хранения данных
- Интегрирован с `dragDropStore` для cross-workspace операций
- Использует `demoPlayerStore` для предпрослушивания треков
