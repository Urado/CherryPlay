# Playlist

Модуль основного плейлиста для создания последовательностей треков.

## Описание

Главный workspace для создания и редактирования плейлистов. Поддерживает drag-and-drop, выделение, группы треков и экспорт.

## Основные компоненты

- **PlaylistView** (`src/workspaces/playlist/PlaylistView.tsx`) - Основной компонент
- **projectStore** - Используется для хранения данных плейлиста

## Функциональность

- Добавление треков через drag-and-drop из FileBrowser
- Переупорядочивание треков внутри плейлиста
- Выделение треков (single, multiple, range)
- Группы треков (создание, расформирование, переименование)
- Отображение общей длительности плейлиста
- Отображение длительности каждого трека (у строк, отмеченных как дубликат по пути или по имени файла, — длительность показывается у каждой)
- Предупреждение о дубликатах: красная точка рядом с длительностью; подсказка при наведении совпадает с UI: «Дубликат: такой трек уже есть в списке (по пути или имени файла)»
- Undo/Redo (Ctrl+Z / Ctrl+Y)
- Сохранение/загрузка проектов (`.cherry`): в десктопе команды **Новый проект**, **Открыть проект…**, **Сохранить**, **Сохранить как…** в меню проекта (иконка **⋮**) в шапке; подробно — [Save/Load](../systems/save-load.md)
- Экспорт плейлиста

## Таймлайн и отсечки

Отсечки (интервал, конец очереди, план) в списке **того же проекта** считаются через `usePlayerDividers` и отображаются с той же приоритизацией и форматом времени, что и в плеере. Подробно: раздел «Отсечки таймлайна в списке треков» в [документации Player](player.md).

## Интеграция

- Использует `projectStore` для хранения данных
- Интегрирован с `dragDropStore` для cross-workspace операций
- Использует `demoPlayerStore` для предпрослушивания треков
