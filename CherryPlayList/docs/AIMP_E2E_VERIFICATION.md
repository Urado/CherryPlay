# AIMP Integration — End-to-End Verification Checklist

Проверка полного сценария: состояние воспроизведения и плейлист из AIMP проходят через CherryPlayList и отображаются на сайте вечеринки. Чеклист используется как gate перед релизом фичи или после изменений в AIMP/Electron/стриминге.

**Окружение:** Windows x64, CherryPlayServer и CherryPlayWeb доступны, AIMP x64 с установленным плагином CherryPlayAimpBridge.

---

## 1. Окружение и gating

| #   | Проверка                                                                                               | Ожидание                                                                                                         | Pass/Fail |
| --- | ------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | --------- |
| 1.1 | Запуск CherryPlayList на Windows x64, источник «CherryPlay Player»                                     | Пресет «AIMP + Party» в списке layout **не** показывается                                                        |           |
| 1.2 | Переключение источника на «AIMP» при валидном манифесте (`plugins/CherryPlayAimpBridge/manifest.json`) | Источник AIMP выбран, окружение eligible, пресет «AIMP + Party» **появляется** в выборе layout                   |           |
| 1.3 | Выбор пресета «AIMP + Party»                                                                           | Слева — workspace AIMP, справа — Party; в AIMP панели отображается статус (слушает / ожидание плагина и т.д.)    |           |
| 1.4 | Переключение источника обратно на «CherryPlay Player»                                                  | Пресет «AIMP + Party» снова скрыт; при активном layout «AIMP + Party» происходит переключение на fallback-пресет |           |

## 2. Подключение плагина и состояния

| #   | Проверка                                                                 | Ожидание                                                                     | Pass/Fail |
| --- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------- | --------- |
| 2.1 | При выбранном источнике AIMP запустить AIMP x64 с установленным плагином | В панели AIMP статус переходит в «подключён», отображается версия плагина    |           |
| 2.2 | В AIMP есть плейлист с треками                                           | В панели AIMP отображается read-only список треков, активный трек выделен    |           |
| 2.3 | В AIMP воспроизводится трек                                              | Внизу панели AIMP отображается прогресс текущего трека                       |           |
| 2.4 | Кнопка «Старт стриминга» до нажатия                                      | Состояние на сайт **не** уходит (на странице вечеринки нет/старое состояние) |           |
| 2.5 | Нажатие «Старт стриминга» при подключённом плагине и валидных snapshot   | Трансляция на сервер/сайт начинается                                         |           |

## 3. Отображение на сайте

| #   | Проверка                                                                       | Ожидание                                                                         | Pass/Fail |
| --- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | --------- |
| 3.1 | Открыть страницу вечеринки (shortCode) в CherryPlayWeb после «Старт стриминга» | На сайте отображается плейлист из AIMP, текущий трек и прогресс совпадают с AIMP |           |

| 3.3 | Изменение плейлиста в AIMP (добавление/удаление/порядок)                       | На сайте плейлист обновляется в соответствии с AIMP                              |           |

---

## 4. Обрыв и восстановление

| #   | Проверка                                                                      | Ожидание                                                                                                                  | Pass/Fail |
| --- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | --------- |
| 4.1 | Закрыть AIMP во время активного стрима                                        | В панели AIMP статус — отключено/устарело; на сайте состояние **замораживается** (freeze), не сбрасывается сразу          |           |
| 4.2 | Через 1 минуту без реконнекта                                                 | На сайте блок «сейчас играет» скрывается (playbackState обнуляется), плейлист и проигранные остаются                      |           |
| 4.3 | Запустить AIMP снова, дождаться подключения плагина, нажать «Старт стриминга» | Трансляция возобновляется, на сайте снова отображается актуальное состояние                                               |           |
| 4.4 | Перезапуск CherryPlayList при запущенном AIMP и плагине                       | После перезапуска приложения и выбора источника AIMP плагин переподключается; после «Старт стриминга» трансляция работает |           |

## 5. Переключение обратно на CherryPlay Player

| #   | Проверка                                                                                      | Ожидание                                                                                                                                              | Pass/Fail |
| --- | --------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| 5.1 | Во время активного стрима из AIMP переключить источник на «CherryPlay Player»                 | Трансляция от AIMP прекращается; пресет «AIMP + Party» скрывается; при выборе layout «Вечеринка (Player + Party)» стриминг идёт от встроенного плеера |           |
| 5.2 | Запустить сессию встроенного плеера (Player workspace), создать вечеринку, подключиться к Hub | Состояние встроенного плеера транслируется на сайт как раньше, без остаточного влияния AIMP                                                           |           |

## 6. Негативные сценарии

| #   | Проверка                                                                                                     | Ожидание                                                                         | Pass/Fail |
| --- | ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | --------- |
| 6.1 | Попытка нажать «Старт стриминга» при отключённом плагине                                                     | Кнопка недоступна или показывается сообщение о необходимости подключения плагина |           |
| 6.2 | Несовпадение версии протокола (если доступна старая/новая версия плагина)                                    | Handshake завершается отказом, в логах/UI есть указание на несовпадение версии   |           |
| 6.3 | Отсутствие манифеста (удалить/переименовать `plugins/CherryPlayAimpBridge/manifest.json`) при выбранном AIMP | Источник AIMP недоступен или показываются gating reasons (манифест не найден)    |           |

---

## Итог

- **Pass:** все критичные пункты (отображение на сайте, freeze при обрыве, переключение источника) пройдены.
- **Fail:** любой критичный пункт не выполнен — результат передать в соответствующий шаг (Electron/плагин/Frontend) для исправления, критерии верификации не ослаблять.

После прогона заполнить Pass/Fail и сохранить чеклист (например, в истории релиза или в задаче).
